# ArduinoCpuTemp

Индикация температуры процессора на трёх светодиодах, подключённых к Arduino.
Скрипт на Windows читает температуру CPU через Open Hardware Monitor и раз в секунду
отправляет её по USB (Serial) на плату. Arduino зажигает нужный светодиод в зависимости
от диапазона температуры.

## Как это работает

```
┌────────────────────┐   Serial 9600   ┌──────────────────┐
│  ПК (Windows)      │ ──────────────► │   Arduino        │
│  control.py        │   "<temp>\n"    │   sketch.ino     │
│  читает t° CPU     │                 │  зажигает LED    │
│  через WMI / OHM   │                 │  по диапазону    │
└────────────────────┘                 └──────────────────┘
```

Пороги индикации (задаются в скетче):

| Температура CPU | Светодиод      | Пин |
|-----------------|----------------|-----|
| 40–55 °C        | LED1 (норма)   | 3   |
| 56–69 °C        | LED2 (тепло)   | 4   |
| 70 °C и выше    | LED3 (горячо)  | 5   |

Ниже 40 °C состояние светодиодов не меняется (последнее активное сохраняется).

## Требования

Железо:
- Arduino (Uno / Nano / любая совместимая плата)
- 3 светодиода + токоограничивающие резисторы (обычно 220–330 Ом)
- USB-кабель

Софт (только Windows):
- [Open Hardware Monitor](https://openhardwaremonitor.org/) — источник данных о температуре
- Python 3
- Python-библиотеки: `wmi`, `pyserial`

  ```bash
  pip install wmi pyserial
  ```

> Скрипт использует WMI-провайдер Open Hardware Monitor (`root\OpenHardwareMonitor`),
> поэтому работает только на Windows. На Linux/macOS в текущем виде запускаться не будет.

## Схема подключения

Светодиоды подключаются к цифровым пинам через резисторы:

```
Pin 3 ──[220Ω]──►|── GND   (LED1)
Pin 4 ──[220Ω]──►|── GND   (LED2)
Pin 5 ──[220Ω]──►|── GND   (LED3)
```

## Установка и запуск

### 1. Прошейте Arduino

1. Откройте `sketch_dec31a.ino` в Arduino IDE.
2. Выберите свою плату и порт в меню **Tools**.
3. Нажмите **Upload**.

### 2. Запустите Open Hardware Monitor

Программа должна быть открыта и работать в фоне — иначе температура не считается.

### 3. Настройте и запустите скрипт

В `control.py` укажите свой COM-порт (по умолчанию `COM5`):

```python
arduino_port = "COM5"  # замените на ваш порт
```

Порт можно посмотреть в Arduino IDE (**Tools → Port**) или в Диспетчере устройств.

Затем запустите:

```bash
python control.py
```

В консоли будет выводиться текущая температура, а на плате — загораться
соответствующий светодиод. Остановка — `Ctrl+C`.

> Порядок важен: сначала прошейте плату, потом запускайте `control.py`.

## Частые проблемы

- **`could not open port COM5`** — неверный порт или он занят. Закройте Serial Monitor
  в Arduino IDE и проверьте номер порта.
- **Температура всегда 50 °C** — не запущен Open Hardware Monitor либо сенсор CPU
  не найден (скрипт возвращает 50 как значение по умолчанию).
- **Светодиоды не реагируют** — проверьте, что baud rate 9600 совпадает в скетче и в
  скрипте, и что светодиоды подключены к пинам 3, 4, 5.

## Файлы проекта

- `control.py` — хост-скрипт для Windows: читает t° CPU и шлёт в Serial.
- `sketch_dec31a.ino` — скетч Arduino: принимает температуру и управляет светодиодами.
