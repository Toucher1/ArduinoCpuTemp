# ArduinoCpuTemp
Для работы нужно установить программу openhardwaremonitor(openhardwaremonitor.org) python3 и библиотеки wmi и serial(pip install wmi pyserial).
В файле control.py в 6 строке замените com5 на ваш порт.
Сначало загрузите скетч в плату, а после запускайте control.py иначе ничего не будет работать.
